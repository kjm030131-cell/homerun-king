# gameplay 파트 기록 (rb-gameplay)

> 소유: `shared/**`, `src/index.js`, `tests/**`, `client/game/**`. 이벤트 명세는 [events.md](events.md).
> 두 모드 공통 금지: 공 위치 미리보기 · 투수가 뛰어다니며 수비 · 템포 너무 빠르거나 느리게(TEMPO 1.15 그대로).

## 1. 구조
- `shared/rules.js` — `RULES.real`, `RULES.casual`. `Game`은 `this.R`(= `rulesOf(set.rules)`)로 읽는다.
- 모드 고르기: `new Game({ rules: 'casual' })` 또는 방 설정 `{ t:'set', rules:'casual' }`(방장). 규칙을 바꾸면 이닝 기본값도 그 모드 값으로(이닝을 같이 보내면 그 값).
  혼자하기는 `startLocal(name, { ..., rules })` — **ui 파트가 메뉴에서 넘겨줄 것**.
- 스냅샷 새 키: `ru`(규칙 id), `hx`(사람 타자 실제 판정 폭 배율 = 난이도 × 모드 × 클러치), `sq`(이번 타석 최근 구종 4개), `ev`(이벤트).
- 클라 `hitEase()`는 `S.hx`를 우선 사용 → 클라가 즉시 계산하는 "맞았다/안 맞았다"가 서버 판정과 항상 같다.
- 시간제 `set.timeLim`(분, 0~60): 시간이 지난 뒤 시작하는 이닝이 마지막 이닝. 기본 0(끔).

## 3. 캐주얼 모드 v1
목표: 친구끼리 10~15분 한 판, 첫 판부터 장타·역전·접전이 자주.

| 규칙 | 값 | 이유 |
|---|---|---|
| 이닝 | 3 | 한 판 AI 기준 약 14분(게임 시계) |
| 연장 | 1회까지, **승부치기 무사 1·2루**, 그래도 같으면 무승부 | 연장이 길어지는 것 방지 + 마지막에 아슬아슬 |
| 콜드게임 | 2회 이후 10점 차 | 일방적인 판 빨리 끝냄 |
| 판정 폭 | 리얼 × 1.22 (보통 = 1.89) | 서툰 스윙 흉내 타율 .38, 맞힘률 61%, 삼진율 10% (리얼 .24 / 44% / 23%) |
| 맞힌 공 질 보정 | 0.7 (리얼 0.85) | 빗맞아도 타구가 덜 죽음 |
| 타구 속도 | ×1.06 (모든 타자) | 펜스·물리는 공통으로 두고 장타만 늘림. 사람 흉내 홈런/타석 .11 |
| 막판 보정(클러치) | 마지막 이닝 이후 1~3점 지는 팀 타자: 판정 폭 ×1.12, 타구 속도 ×1.03 | 역전 기회. 이기는 팀 보정은 없음 |
| CPU 강공 비율 | 40% | CPU 팀도 장타가 나와야 시소 경기 |
| CPU 수비 포구 범위 | ×0.9 | 안타↑ (사람이 조작하는 수비수는 그대로) |
| 수비 조작 | 자동 전환 고정(`fieldCtl: 'auto'`), 공 들고 0.9초 가만있으면 CPU 송구, 안 움직이면 CPU가 쫓아감 | 타격·투구에 집중. 원하는 사람만 직접 |
| 사람 투수 | 제구 오차 ×0.8, 퍼펙트 구간 0.80~0.98(리얼 0.84~0.97), 체력 소모 ×0.5 | 투수도 쉽고 재밌게 |
| 3루 코치 | 더 과감(-0.25) | 홈 승부가 자주 |
| 공 위치 미리보기 | 없음 | 규칙 |

AI끼리 3이닝 160경기 (팀당): 득점 3.1 · 안타 4.1 · 홈런 1.3 · 장타 2.4 · 삼진 3.2 · 볼넷 1.0 · **역전 0.5회/경기 · 2점 차 이내 66% · 무승부 1%** · 14분.

검토 후 버린 것: 카운트 1-1 시작 — AI 80경기에서 삼진이 3이닝 4.3개(9이닝 환산 13개)로 늘고 득점은 줄어 지루해짐.

### 사용자 결정이 필요한 것
1. **카운트 1-0 시작**(타자 유리): 득점 +0.4, 볼넷 1.0→1.7, 한 판 2분 짧아짐. 대신 2점 차 이내 경기 66%→58%. 지금은 0-0.
2. **시간제 기본값**: 지금 0(끔). 예: 15분으로 하면 시간이 지난 뒤 시작하는 이닝이 마지막.
3. **클러치 보정**: 지는 팀만 살짝 쉬워지는 것 — 친구끼리 공정하다고 느낄지. 끄려면 `clutch: null`.
4. 캐주얼 콜드게임 10점 — 3이닝이면 2회 끝(=2/3 진행)에만 걸림. 없애도 됨.

## 4. 다른 파트에 요청
- **ui**: 메뉴/방 설정에 모드 선택(리얼/캐주얼) → `startLocal(..., { rules })`, 방은 `{ t:'set', rules }`. 시간제 선택(`timeLim`). 투수 구종 바에 `S.sq`(최근 구종)로 "같은 공 연속" 표시. HUD는 `contact.grade`·`pow`로 타격 문구 색·크기. 설정의 "타격 보조"는 이제 자석 보정 + 타이밍 표시만(위치 표시 없음)이라 설명 문구 수정.
- **anim**: 투구 클립 릴리스 프레임 = `windup.at + 1.85s`(시간표는 events.md). `dive`·`slide`·`catch`(`jump`/`dive`/`fly`)·`throw`(`T`) 이벤트로 클립 재생.
- **audio**: 타격음은 `localSwing`(내 스윙, 즉시) + `contact.pow`/`grade`, 심판 콜은 `strikeCall`/`ballCall`/`out`(kind k), 관중은 `score.go`(역전/앞서감)·`hr`·`catch.robbed`·`safe.close`.
- **stadium**: 없음.
- (반영 완료) audio 요청 필드: contact{foul}, catch{pitch,kmh,x,z,dive} — 포수가 투구 받을 때도 `catch pitch:1`, out/safe{call,x,z,k}, hr{walkoff}, windup{b,s,o,on,sc}, modeChange{rules}. audio의 배너→이벤트 임시 변환은 통합 때 제거 가능.
