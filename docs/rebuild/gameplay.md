# gameplay 파트 기록 (rb-gameplay)

> 소유: `shared/**`, `src/index.js`, `tests/**`, `client/game/**`. 이벤트 명세는 [events.md](events.md).
> 두 모드 공통 금지: 공 위치 미리보기 · 투수가 뛰어다니며 수비 · 템포 너무 빠르거나 느리게(TEMPO 1.15 그대로).

## 1. 구조
- `shared/rules.js` — `RULES.real`, `RULES.casual`. `Game`은 `this.R`(= `rulesOf(set.rules)`)로 읽는다.
- 모드 고르기: `new Game({ rules: 'casual' })` 또는 방 설정 `{ t:'set', rules:'casual' }`(방장). 규칙을 바꾸면 이닝 기본값도 그 모드 값으로(이닝을 같이 보내면 그 값).
  혼자하기는 `startLocal(name, { ..., rules })` — **ui 파트가 메뉴에서 넘겨줄 것**.
- 스냅샷 새 키: `ru`(규칙 id), `hx`(사람 타자 실제 판정 폭 배율 = 난이도 × 모드 × 클러치), `sq`(이번 타석 최근 구종 4개), `ev`(이벤트).
- 클라 `hitEase()`는 `S.hx`를 우선 사용 → 클라가 즉시 계산하는 "맞았다/안 맞았다"가 서버 판정과 항상 같다.
- 시간제 `set.timeLim`(분, 0~60): 시간이 지난 뒤 시작하는 이닝이 마지막 이닝. 기본 0(끔).

## 4. 타격 방식 v2 — PCI(MLB 더쇼식 커서) + 타이밍 위주 (사람 타자만, CPU 타자는 예전 `SWING` 그대로)
사용자 선택: "MLB 더쇼식 PCI + 타이밍 위주 섞기". 코드: `shared/sim.js` `PCI`·`pciJudge`·`pciQ`·`evalPCI`, 클라 `client/game/batting.js`(그리기·즉시 판정 문구), HUD `client/ui/hud.js swingReport`.

### 조작
| 입력 | 동작 |
|---|---|
| 마우스 | 존 위 둥근 사각 커서(PCI) 이동. 커서 안 가로 눈금 2줄 = 땅볼/라인드라이브/뜬공 경계 |
| 좌클릭·Space | 정타: 커서 큼, 타이밍 창 넓음 |
| 우클릭·F | 강타: 커서·타이밍 창 약 76%, 타구 속도 ×1.1, 발사각 +9°(잘 뜸) (F 누르고 있으면 커서가 강타 크기로 보임) |
| B | 번트 (예전과 같음) |
| 테두리 초록 | 타이밍 창 한가운데 55% (시간만 알려줌, 공 위치는 절대 안 보여줌) |

### 판정 (결정적 → 클라 즉시 판정 = 서버 판정)
1. 타이밍: `|dt| > W`면 헛스윙(빠름/늦음). 아니면 정확도 `tq = 1 - |dt|/W`.
2. 커서: 판정 커서 = 그려진 PCI × `(1 + 0.6·tq)` → **딱 맞는 타이밍이면 1.6배** = 타이밍 맞으면 대충 맞춰도 맞음. 공이 그 안(`(|nx|^3+|ny|^3)^(1/3) ≤ 1`)이면 맞음.
3. 타구 질 `q = tq'^0.85 · (1 - 0.45·n²)` (타이밍이 주, 커서 중심 거리는 보조). `tq'`는 난이도·모드 배율을 `ease^0.4`만 받음 → 쉬운 모드는 '맞히기'가 쉬워지고 홈런이 폭증하진 않게.
4. 발사각 = `LIFT_H` 12°(강타 21°) − 34°·ny ± 8° (11-19 '뜬공 기준 명확' 피드백 값을 PCI에도 그대로): 공이 커서 **아래쪽**(커서가 공보다 위) → 땅볼, 가운데 → 라인드라이브, **위쪽** → 뜬공. 질 좋은 타구는 15° 쪽으로 살짝 모음(리얼 25%, 캐주얼 35%).
5. 방향 = −46°·(dt/W) − 10°·nx: **빠르면 당겨치기**(좌측), 늦으면 밀어치기.
6. 파울: 타이밍 끝자락(tq<0.25) 또는 커서 가장자리(n>0.8)일수록 자주 + 기본 12%. 커서 맨 끝(n>0.88) 절반은 빗맞은 약한 타구.
7. 타구 속도는 예전 식 `(31.5 + 20.2q)·pow + 0.1·(구속-35)` 그대로.
8. 자석 보정(공 쪽으로 커서 당기기)은 없앰 — 숨은 보정 대신 '그려진 커서 = 판정 커서'(+타이밍 보너스).

## 4-1. 난이도 조정 (11-23) — 값 2개: `RULES.real.humanQ` 1.0→**1.3**, `RULES.casual.humanQ` 1.0→**1.1**

- 측정 (보통 사람 흉내 = 타이밍 σ100ms·커서 σ14cm, CPU 투수 보통, 시드별):

## 5-2. 좌타자 (11-23, [lefty])
- 속성: 선수마다 `bats` 'R'/'L'/'S'. 사람 = 설정 > 화면 '내 타석'(localStorage `hr_bats`, 메시지 `{t:'bats', v}`, 다음 타석부터 — 혼자하기는 시작 때, 멀티는 접속 때·바꿀 때 보냄). CPU = `cpuBats(구단, 팀, 타순)` 고정(180명 중 좌 28%·스위치 6% → 좌타석 34%, MLB 좌타 ~28%+스위치 ~4%).
- 스위치: 투수 반대쪽(`PITCHER_HAND` = 1, 투수 모델·클립이 전부 우투라 지금은 늘 좌타석). 좌우 상성(플래툰) 보정은 안 넣음 — 투수가 모두 우투라 넣으면 좌타가 일방적으로 유리해짐.
- 타석 방향 `batter.h`(1 우·−1 좌)는 서버가 정해 스냅샷 `s.bat.h` 로 → 클라는 그 값으로만 그림(서버·클라 같은 값).
- 판정: PCI 맞힘·질·발사각은 좌우 대칭이라 그대로(클라 즉시 판정 = 서버). 방향만 거울: `evalSwing/evalPCI(..., hand)` 가 가로 오차(ax·nx)를 반전해 넣고 spray 를 반전 → 좌타는 빠르면 우측(−x)으로 당겨침, 늦으면 좌측. 파울·빗맞은 타구 방향도. CPU 타자 분포도 같은 식. 몸에 맞는 공 = `tx·h > 0.56`.
- 테스트 `batting.test.mjs` '좌타자': 좌타 빠름 spray < −15°, 늦음 > +10°, CPU 반전, handOf, 좌타 설정 → `s.bat.h = −1`.

## 6. 다른 파트에 요청
- **ui**: 메뉴/방 설정에 모드 선택(리얼/캐주얼) → `startLocal(..., { rules })`, 방은 `{ t:'set', rules }`. 시간제 선택(`timeLim`). 투수 구종 바에 `S.sq`(최근 구종)로 "같은 공 연속" 표시. HUD는 `contact.grade`·`pow`로 타격 문구 색·크기. 설정의 "타격 보조"는 이제 타이밍 표시만(자석 보정 없음, 위치 표시 없음) — 설명 문구는 gameplay가 최소로 고쳐 둠(index.html 설정·조작법).
- **anim**: 투구 클립 릴리스 프레임 = `windup.at + 1.85s`(시간표는 events.md). `dive`·`slide`·`catch`(`jump`/`dive`/`fly`)·`throw`(`T`) 이벤트로 클립 재생.
- **audio**: 타격음은 `localSwing`(내 스윙, 즉시) + `contact.pow`/`grade`, 심판 콜은 `strikeCall`/`ballCall`/`out`(kind k), 관중은 `score.go`(역전/앞서감)·`hr`·`catch.robbed`·`safe.close`.
- **stadium**: sim 지면·벽·폴대 경계를 field.js/fence.js 그림에 맞췄음(`surface`, `WALL_FOUL`, `DUG_SPAN`, `netH`, `POLE`). 그림을 바꾸면 sim 쪽도 같이 알려 주기.
- **ui**: (gameplay가 최소로 고침) `hud.js swingReport`가 이제 `pciJudge` 결과(J)를 받아 둥근 사각 커서를 그림, 조작 안내·도움말 카드 문구 '배트 원'→'PCI 커서'. `index.html` 조작법(H) 타격 절·타격 보조 설명.
- (반영 완료) audio 요청 필드: contact{foul}, catch{pitch,kmh,x,z,dive} — 포수가 투구 받을 때도 `catch pitch:1`, out/safe{call,x,z,k}, hr{walkoff}, windup{b,s,o,on,sc}, modeChange{rules}. audio의 배너→이벤트 임시 변환은 통합 때 제거 가능.
