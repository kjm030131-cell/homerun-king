      설정

      노트북이 버벅이면 그래픽을 "빠르게"로. 그림자·빛 번짐·해상도가 낮아져.

      메뉴

      조작법

      타격

      마우스로 하얀 배트 원을 공이 올 자리에 맞추고, 공이 들어오는 순간 좌클릭/Space = 정타 스윙(원 큼), 우클릭/F = 강타(원 작고 멀리 감). 원이 공보다 아래면 뜬공, 위면 땅볼. 빠르면 당겨치기(좌측), 늦으면 밀어치기(우측).

      타이밍: 화면 위 투구 신호 바가 셋 → 다리 들기 → 정점 → 스트라이드 → 온다! 순서로 차. 투수가 다리를 들었다가 잠깐 멈춘 뒤 내딛는 순간 공이 나와. 스윙하면 왼쪽 아래 스윙 분석에 타이밍(빠름/늦음)과 배트 원 위치가 얼마나 빗나갔는지 떠서 뭐가 문제였는지 알 수 있어. 배트 원 테두리가 초록으로 바뀌는 순간이 타이밍 딱. 공이 지나가면 구종 색으로 궤적이 잠깐 남아(포심 빨강·슬라이더 파랑·커브 보라·체인지업 초록·스플리터 노랑). V 타격 시점 전환. 설정 > 타격 보조 "연습용"이면 공 들어올 위치까지 보여줘. 타격 난이도(혼자하기·방 설정): 쉬움 = 배트 원·타이밍 폭이 넓고 공이 조금 느리며, 공이 반쯤 오면 들어올 자리에 작은 점이 떠.

      번트

      투구 전에 B 또는 화면의 번트 자세 버튼 → 배트가 공 높이를 자동으로 따라가. 공 들어올 때 클릭만 하면 돼. 커서를 좌우로 두면 3루/1루 쪽으로 굴러가. 2스트라이크에서 번트 파울은 삼진.

      투구

      1~6 구종 → 마우스로 코스 찍고 클릭 → 게이지가 차오르면 한 번 더 클릭. 초록 구간에서 멈추면 최고 구속·정확한 제구. 빨강까지 넘기면 더 빠르지만 공이 흔들려. 많이 던지면 체력이 떨어져 구속·제구가 나빠져. 주자가 있으면 Q 견제 (타석당 3번).

      수비

      WASD 이동 · Shift 전력질주 · Space 점프 · C 다이빙. 공 가까이 가면 자동 포구, 주황 원이 낙구 지점. 공 잡으면 11루 22루 33루 4홈 F투수 R중계(커트맨에게) — 외야 깊은 곳에선 유격수·2루수가 파란 원으로 나와 중계해. 톡 누르면 정확하게, 꾹 누르면 강송구(빠르지만 빗나갈 수 있음). 베이스 위 숫자가 누를 키고, 금색이 주자가 가는 베이스. 공 든 채로 베이스 밟으면 포스아웃, 주자에 닿으면 태그아웃. 손 놓으면 CPU가 대신 움직여.
      투구 전에는 WASD로 수비 위치를 옮겨 시프트할 수 있어. 기본 수비 카메라는 내 선수 뒤 3인칭(화면 드래그로 회전)이라 W는 화면 앞쪽. V로 홈 뒤 중계 시점과 전환. 공을 향한 띠가 초록이면 뛰어가면 잡고, 노랑이면 다이빙/점프가 필요, 빨강이면 어려움. 땅볼은 하늘색 링이 막을 지점. 노란 링이 지금 내가 조작하는 선수. 타구가 뜨면 공 쫓는 수비수로 조작이 자동으로 넘어가고(방 설정), Q로 공에 가장 가까운 수비수로 직접 바꿀 수 있어. 송구하면 받는 선수로 조작이 따라가.

      주루

      기본은 자동. E 전 주자 한 베이스 더 · Q 귀루 · Space 슬라이딩(베이스 4.5m 앞) · R 투구 전 도루 (너무 일찍 누르면 견제당하기 쉬워).

      기타

      Enter 채팅 · T 빠른 채팅 · Tab 기록판 · Esc 메뉴
